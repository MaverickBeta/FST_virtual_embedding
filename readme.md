# FST-VB: OV Circuit Pure Concept Clustering Analyzer

This repository contains the official evaluation pipeline for analyzing and quantifying "Pure Concept Clustering" within the **OV Circuits** of Transformer models. It specifically provides tools to benchmark the conceptual isolation capabilities of **FST (Feature/Predictive)** architectures against Standard Transformers.

By injecting a clean, unpolluted vocabulary embedding matrix ($\bar{E}$) directly into the $W_{OV}$ circuit of each attention head, this toolkit allows researchers to observe and quantify how well models disentangle grammatical and semantic concepts (Nouns, Verbs, Adjectives, Adverbs) in high-dimensional (2048-D) space.

## Requirements & Installation

We highly recommend using a Conda environment. The rendering engine has been heavily optimized for CPU multi-processing to strictly prevent OOM (Out Of Memory) crashes and CUDA Context deadlocks during massive rendering tasks.

Bash
pip install torch transformers accelerate
pip install numpy pandas scikit-learn scipy
pip install matplotlib seaborn nltk
(Note: For nltk, the script will automatically download the words and averaged_perceptron_tagger corpora upon first run).

## Quick Start: The 4-Step Evaluation Pipeline
Please ensure you are running all commands from the root directory (FST_VB/).

Step 1: Extract Pure Vocabulary
Extract highly representative, unpolluted words (filtering out stop words and short tokens) and assign them POS tags using NLTK.

Bash
python scripts/extract_top_words.py --top_n 200
Output: data/top_200_words.json

Step 2: Extract 2048-D OV Embeddings (The Gold Mine)
Inject the pure vocabulary embeddings into the Predictive Blocks (FST) and Physical Blocks (Standard Transformer), bypassing contextual pollution.

Extract FST Model:

Bash
python scripts/extract_ov_embeddings.py \
    --model_path "models/fst_1_3B_local" \
    --save_path "data/fst_ov.pt"
Extract Standard Transformer:
(Note: The script automatically aligns the physical layers of the standard transformer to match the predictive blocks of the FST).

Bash
python scripts/extract_ov_embeddings.py \
    --model_path "williamconvertino/transformer_1_3B" \
    --save_path "data/std_transformer_ov.pt"
Output: data/fst_ov.pt and data/std_transformer_ov.pt

Step 3: Comprehensive Quantification & Memory-Safe Rendering
Calculate the Target-Class Silhouette Score (Cosine Metric) in 2048-D space for all 12 layers × 32 heads × 4 Tags.
The script uses a stateless FigureCanvasAgg backend to guarantee zero memory leaks while rapidly generating target-focused t-SNE comparisons.

Bash
# To generate the CSV and plot the Top-3 heads per layer/tag:
python scripts/comprehensive_eval.py --top_k_plots 3

# To go full-throttle and plot all 32 heads (generates ~1500+ images safely):
python scripts/comprehensive_eval.py --top_k_plots 32

# To ONLY calculate the CSV scores without plotting (Instant):
python scripts/comprehensive_eval.py --no_plots
Output: comprehensive_results/global_clustering_scores.csv and comprehensive_results/plots/

Step 4: Plot Global Evolution Trends (Paper-Ready Figure)
Consume the generated CSV to plot a 2x2 grid showing how the clustering purity evolves across layers for different POS tags. The chart shares a unified Y-axis for fair cross-tag comparison.

Bash
python scripts/plot_csv_results.py
Output: comprehensive_results/layer_trend_comparison.png

## Evaluation Metrics
Target-Class Silhouette Score: Evaluates the intra-cluster cohesion and inter-cluster separation of a specific concept (e.g., Verb) against all other concepts in the original high-dimensional space.

Convex Hull Focus Visualization: Employs a One-vs-Rest visual paradigm, coloring the target concept in bold red while pushing background points to a low-opacity gray, explicitly highlighting the conceptual boundaries learned by the attention heads.
